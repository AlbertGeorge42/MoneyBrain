# 阶段 0 · 地基（M0–M1）

> **目标**：把「记账这件事本身」做对——口径可信、数据不丢、结构不烂。
> 这一阶段不做同步、不做移动端、不做新功能，只做**让后面的功能有地基可站**的事。
>
> **M0–M1 已收口**，仅余 `A5`、`D4` 两条尾巴。已完成条目的明细见
> 2026-11-04 版 git 历史与 [PROGRESS](PROGRESS.md)，本文件不再复述。

## 前置与约束

目标架构的**唯一来源**是[目标架构](architecture.md)（§1–9）；当前已实现的现状见
[../architecture.md](../architecture.md)，注意区分。本文件不复制架构正文——复制必然漂移，
动手前读对应小节即可。

本阶段仍适用的两条约束：

- **repository 边界**（D1 已落地）：软删除过滤（`deleted_at IS NULL`）与将来的账本过滤
  **只**在 repository 层做，service 层不出现 `prisma.`。
- **同步契约与实体集合解耦**（[stage-2](stage-2-sync.md) F11）：K 批次的表不在本阶段建，
  但容器格式不能依赖实体清单，否则这些表落地时会推翻容器结构。

## 差距清单

### 批次 A · 口径与内核

| # | 现状 | 目标 | 验收 |
|---|---|---|---|
| A5 | 导出文件名里的日期取 `new Date().toISOString()`（UTC 日）：本地 00:00–08:00（UTC+8）导出会落到前一天，与界面展示、交易日期的本地日历日不一致 | 导出日期按**本地日历日**生成，与交易日期、界面展示同一语义；时间戳字段仍存 UTC | 导出日期与界面展示一致（本地跨日后文件名是新一天）；跨 UTC 日边界有测试 |

**A4（本金 + 手续费统一）已评估、推迟**：理由与复审触发条件见
[principles](principles.md) 决策 #22——收入本就是净额、退款 `amount` 同时是可退上限，
改语义不是单位换算。不列入待领；本阶段只留这条指针。

后续不得倒退的硬约束见 [dev-guide §3.2](../dev-guide.md)：分是唯一权威单位（传输也用分，
前端无需换算）、字段名不加单位后缀（`amount` 而非 `amountMinor`）、元只出现在用户输入与文件两个边界。

## 验收基线

- 覆盖导入可一键回到导入前；删除可撤销且有修改历史。
- 四张报表共享同一期间；预算下钻与用量同源；超支显示真实百分比。
- 投资分析不再有第二份现金流口径；属性测试覆盖内核不变量 1–6。
- service 层无 Prisma 调用；列表与报表查询量随期间收敛（余额除外）；并发写不报锁冲突。

**不做**：界面改造见 [stage-1](stage-1-experience.md)；多账本、周期交易、标签见 [stage-4](stage-4-expansion.md)；同步与移动端见[蓝图入口](../rewrite-blueprint.md)的阶段总览。
