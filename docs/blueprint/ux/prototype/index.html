线框说明 · UX1–UX4 与待确认项

本原型是线框级演示：灰阶块、占位文本、结构线框，不做视觉润色。 图表一律是斜纹占位块，颜色不代表 UX4 的令牌（令牌留给 UX5b 高保真阶段）。

已确认结论（UX1–UX4 · 本稿不推翻）

  • UX1 信息架构：主导航 5 项（总览 / 流水 / 报表 / 预算 / 设置），层级两层，每类配置只有一个权威入口。
  • UX2 交互模型：记账 3 步（金额 → 分类 → 保存）；移动端「已连记 N 笔」必须可见；删除可撤销。
  • UX3 平台差异：PC 键盘优先、移动端拇指优先；两端各自设计，不做响应式缩放；移动端总览账户只列 4 个。
  • UX4 设计 token：字号 / 间距 / 圆角阶梯已在本稿成立；色板留到 UX5b。

报表表格口径

  • 表尾合计行：各表的汇总值并入表尾 <tfoot>，与各列底部对齐、数值右对齐、用底色 + 上边框区分合计语义；底部独立的「收入合计 / 支出合计 / 结余」对照行已删除（第三轮）。
  • 两栏合计对齐：两栏并排时两表合计行统一落在较长表格的底部（等高拉伸），不出现左右错位；口径说明两栏共用一条放表格外。
  • 二级分类与折叠：PC 父行左侧三角可折叠子行，子级缩进一级；移动端分段按钮切出的表同样支持折叠。现金流分组行同构（见下）。
  • 合计口径：按一级父分类汇总（父级金额已含其子分类），因此折叠子行不改变合计；各级「占比」均相对合计。该说明同时写在表下（.tbl-note），避免「折了合计没变」的疑问。
  • 一句话结论：PC 与移动端均已移除。
